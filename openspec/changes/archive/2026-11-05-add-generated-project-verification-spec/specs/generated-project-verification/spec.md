# Spec Delta

## Purpose

What a Python script project generated by ai-devkit must be able to prove about itself before a change is accepted.

## ADDED Requirements

### Requirement: Single verification command

A generated project SHALL provide one command that runs every check and exits with a non-zero status when any check reports a failure.

#### Scenario: Invalid source code

- **WHEN** a generated project contains a Python file that violates the configured lint rules
- **THEN** the verification command exits with a non-zero status and reports the lint failure

#### Scenario: Failing test

- **WHEN** a generated project contains a test that fails
- **THEN** the verification command exits with a non-zero status and reports the failing test

#### Scenario: Invalid specification

- **WHEN** a generated project contains an OpenSpec specification that violates the OpenSpec format
- **THEN** the verification command exits with a non-zero status and reports the validation error

#### Scenario: Consistent project

- **WHEN** the source, tests, documentation and specifications of a generated project are all valid
- **THEN** the verification command exits with status zero and modifies no tracked file
